# 最終LLM選択実験プロンプト契約 v1

LLMの仕事は、提示されたコードと候補規則から
候補IDを1つだけ選択することとする。

主比較はモデル間の絶対性能ではなく、各モデル内部での
P0 / P1 / P2 の差とする。

## 条件

- P0: CPU固有情報なし
- P1: CPU製品名 + マイクロアーキテクチャ
- P2: P1 + キャッシュ、ISA、コア構成、SMT、NUMAなどの静的情報

性能実測値、最良候補、候補順位、性能カウンタ値、
過去のLLM回答は一切提示しない。

## 入力表現

- C
- LLVM IR

同じカーネル・同じサイズ・同じ候補集合について比較する。

## 出力

理由説明は要求しない。

出力は次の候補IDのみをJSONとして返す。

{"candidate_id":"..."}

これにより出力トークン数と料金を抑え、
自然言語説明の長さによるモデル間差も避ける。
